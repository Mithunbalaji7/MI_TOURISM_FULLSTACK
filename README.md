 🌍 MI Tourism Development - Full Stack Tourism Management System

MI Tourism Development is a full-stack tourism management website designed to help users explore tourist destinations, hotels, tour packages, events, restaurants, transportation services and other travel information.

The project also provides online tour booking, user registration, login, payment integration, tourism news, gallery and dashboard features.
